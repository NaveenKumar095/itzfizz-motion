# ITZ FIZZ — Motion Experience

A cinematic, scroll-driven automotive hero built as a Next.js App Router project.

## Stack

Next.js, React, TypeScript, Tailwind CSS, GSAP, ScrollTrigger, and `@gsap/react`.

## Features

- Pinned, scrubbed GSAP timeline for car travel, lime motion trail, headline emphasis, and progressive stats.
- Separate restrained load-in sequence.
- Responsive composition across desktop, tablet, and mobile; reduced-motion fallback.
- Accessible semantic copy and descriptive image alternative text.

## Run locally

```bash
npm install
npm run dev
```

Build with `npm run build`.

The generated transparent vehicle asset is at `public/images/car.png`. Deploy on Vercel by importing the repository; no special configuration is required.
